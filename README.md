I'm David, founder of **Tokendivers** in Shanghai. I started shipping iOS apps in 2013. These days I build
native macOS tools, get Linux running on Apple hardware, run my own infrastructure, and build workflows
where AI agents do real engineering work.

## Things I've built

| Project | What it does | Under the hood |
| --- | --- | --- |
| [**Drawer**](https://davidfuzju.github.io/drawer/) | Turns any macOS app into a drawer that slides in from a screen edge on a hotkey | Drives native windows through the Accessibility API · Sparkle auto-update with a beta channel · 8 releases |
| [**WeChat Duo**](https://github.com/davidfuzju/wechat-duo) | Runs a second WeChat on macOS and repairs the copy after WeChat updates overwrite it | Swift / SwiftUI menu bar app · re-signed bundle ID · FSEvents self-healing |
